# 优秀开发工具清单

一份面向 .NET / UI 设计 / 图片浏览场景的实用软件推荐清单，持续更新。

---

## 一、VB.NET 代码编写优秀软件

| 软件 | 亮点 | 适合场景 | 费用 |
|------|------|----------|------|
| **Visual Studio 2022 Community** | 微软官方 IDE，VB.NET 支持最完整，WinForms / WPF 可视化设计器强大，调试、IntelliSense、NuGet 一体 | VB.NET 主力开发，尤其 WinForms 桌面程序 | 免费（个人/小团队） |
| **SharpDevelop** | 开源轻量 .NET IDE，支持 VB.NET / C#，启动快、占用小 | 老旧电脑、只需写代码不想装大 IDE | 免费开源 |
| **LINQPad** | 交互式 .NET 查询与代码片段工具，可即时运行 VB.NET 表达式、调试 LINQ | 快速验证代码、学习 .NET API | 有免费版 / 付费版 |
| **Visual Studio Code + Basic 扩展** | 轻量跨平台编辑器，配合 `Visual Basic` 语法扩展做高亮 | 简单的 VB.NET 文件查看与轻量编辑 | 免费 |
| **.NET SDK（dotnet CLI）** | 命令行编译、构建、运行 VB.NET 项目，CI/CD 必备 | 自动化构建、脚本化编译 | 免费开源 |

> 提示：JetBrains Rider 主要支持 C# / F#，**不支持 VB.NET**，选择时别踩坑。

## 二、UI 界面设计优秀软件

| 软件 | 亮点 | 适合场景 | 费用 |
|------|------|----------|------|
| **Figma** | 在线协作设计，组件/自动布局/原型一体，插件生态丰富，浏览器即用 | 团队协作、专业 UI 设计 | 免费版够用 / 付费进阶 |
| **即时设计（js.design）** | 国产在线设计工具，中文友好，兼容 Figma 文件，无需翻墙 | 国内团队、Figma 替代 | 免费版可用 |
| **墨刀** | 国产原型工具，上手快，可快速做交互原型并分享演示 | 快速出原型、需求演示 | 免费版 / 付费版 |
| **Axure RP** | 专业交互原型，支持复杂逻辑、变量、条件，产出高保真原型 | 产品经理、复杂交互设计 | 付费（有试用） |
| **Sketch** | macOS 原生 UI 设计工具，矢量编辑细腻，插件生态成熟 | Mac 用户、专业 UI 设计 | 付费 |

> 提示：Adobe XD 已进入维护停止开发状态，新项目不建议再选。

## 三、快速看图软件

| 软件 | 亮点 | 适合场景 | 费用 |
|------|------|----------|------|
| **XnView MP** | 支持 500+ 格式，批量重命名/转换，带缩略图管理，跨平台 | 大量图片管理、格式兼容 | 免费（非商业） |
| **Honeyview（蜂巢看图）** | 打开速度极快，界面简洁，支持压缩包/RAW 直接浏览 | 日常快速看图、秒开大图 | 免费 |
| **ImageGlass** | Windows 原生轻量看图，启动快，支持主题与多种格式 | 追求轻量与速度 | 免费开源 |
| **FastStone Image Viewer** | 看图 + 简单编辑 + 批量转换/重命名，功能全面 | 看图顺带处理图片 | 免费（非商业） |
| **IrfanView** | 老牌经典，体积小巧、速度极快，插件丰富 | 低配电脑、极速浏览 | 免费（非商业） |
